侧边备忘录 - 第一次用看这里
==========================================

【怎么启动】
双击「启动备忘录.vbs」（或「启动备忘录.bat」）。
第一次会慢一点，之后它一直在后台待命，屏幕右下角托盘里有个小图标。

【双击时弹出「打开文件 - 安全警告」/ 提示来自 Internet？】
从微信、QQ、网盘下载的压缩包会被 Windows 标成"来自网络"，解压出来的
文件也带着这个标记，双击时就会弹安全警告、或者点了没反应。任选一个办法：
  1. 解压之前：右键 zip 文件 -> 属性 -> 底部勾「解除锁定」-> 确定，再解压
  2. 已经解压了：双击本文件夹里的「一键修复.bat」，它会自动清除标记、
     关掉残留的旧实例并重新打开程序。
（用 7-Zip / Bandizip 解压一般不带这个标记。）

【双击后完全没反应？（没有面板、也没有托盘图标）】
这通常不是程序坏了，而是 Windows 上 Chromium 的"沙箱"初始化失败，
程序会不打任何招呼地直接退出（看着就像没运行）。
解决办法：本文件夹里的启动脚本已经统一带了 --no-sandbox 参数，
正常双击即可。如果你是手动在命令行里启动，记得带上这个参数：
    node_modules\electron\dist\electron.exe . --no-sandbox
（本程序只加载本地页面、不联网，关掉沙箱没有安全影响，放心用。）

【怎么用】
- 默认：鼠标移到屏幕最右边 -> 面板自动滑出来；鼠标移开 -> 自动收回去
- 嫌划边容易误碰？点面板右上角 ⇱ -> 「唤出方式」-> 选「边缘细把手，点击才打开」：
  屏幕边缘只留一条 8 像素宽的小细条，不挡桌面；划过去不会弹，点它才展开；
  展开后鼠标移开还是会自动收回。想换回来在同一个地方选另一项即可。
- 面板上点「+」新建备忘；点卡片左边的圆圈打勾表示做完了
- 有些任务只在一段时间里有效（选课窗口、报名期、上课时段）：编辑页里填
  「生效时段」的开始 / 结束时间。没到开始时间会灰掉并标「未开始」，
  到点自动变「进行中」，过了结束时间标「已结束」，卡片上会写出区间。
  状态会自动更新，但都不会自动打勾、不会消失——已结束仍由你自己决定
  做没做完。两个都留空就是普通备忘，跟以前完全一样。
  设了每天 / 每周重复时，只取你填的时分套到每一期（例：每周三 10:00→11:40）。
- 面板右下角有个小三角，按住拖动可以调整整个页面的大小；
  同一个菜单里点「恢复默认页面大小」就能复位。
- 面板叫不出来 / 感觉卡住了 -> 按 Ctrl + Alt + M，一下就出来，再按一下收回去
  （不用退出重开）
  万一这个键被别的软件（QQ、输入法等）占了，程序会自动换成 Ctrl + Alt + N
  或 Ctrl + Shift + M。托盘图标右键菜单最上面那行会写清楚现在用的是哪个。

【开机自动启动】
托盘图标右键 -> 「开机自启」打勾。

【换位置】
托盘右键 -> 「窗口位置」（或点面板右上角 ⇱）：右侧贴边 / 顶部贴边 / 小浮窗。
默认是右侧贴边。切换后程序会自动重启一次（约 2 秒），这是故意的，
用来彻底避开「切换后界面卡住」，重启后笔记一条不少。
换成小浮窗后拖乱了，可以用「重置小浮窗位置」复位；
收成小气泡之后：点一下（或双击）气泡就展开；按住拖动可以换位置，
不用先展开。拖动时不会误触展开，两件事可以同时用。
注意：小浮窗模式不响应鼠标划边，也不受「唤出方式」影响，
要靠点气泡 / 托盘图标 / 快捷键叫出来。

【数据存在哪】
程序文件夹里的  memo-userdata\  目录（和启动脚本在一起）。
纯本地，不联网。想备份就把整个 memo-userdata 文件夹复制一份；
想换电脑就把整个程序文件夹一起拷过去，双击即用。

注：2026-11-02 起从系统的 AppData 目录搬到了这里。
原因是有些电脑上 AppData 会被拒绝写入，导致"改了不保存""托盘图标不见"。
首次启动会自动把旧笔记复制过来，旧文件保留不删除，不会丢数据。

【手机同步（可选，用不上就跳过）】
想用手机看/改备忘才需要：托盘右键 -> 「手机同步」那一组 -> 点「开启手机同步」，
会弹出一个窗口，里面写着网址和 6 位配对码，按里面的提示连。
手机和电脑要在同一个 WiFi 下。详见「手机同步-使用说明.md」。

【桌面快捷方式】
方法一：装了 Python 的话，双击「重建桌面快捷方式.py」
方法二：右键「启动备忘录.vbs」-> 发送到 -> 桌面快捷方式（一样能用）

【遇到问题】
先看「面板找不到-自救说明.md」，里面按现象列了各种情况的解决办法。
