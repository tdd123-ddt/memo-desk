# 侧边备忘录（memo-desk）

一个贴在屏幕边缘的桌面备忘录小工具：平时缩成一条贴边细条，鼠标一靠近就**缓缓滑出**，看完自动收回，不占地方。

**窗口位置**：可以贴在**右侧**、贴在**顶部**，或者变成一个**可拖动的小浮窗**，随时一键切换。
**外观**：默认「毛玻璃」半透明卡片，卡片沿一条弧线排布、滚动时像在弯道上流动；也可以切换成「暗夜玻璃」或「简约浅色」，曲线弧度可调、可关。

## 下载与安装

最新版本 **v1.1.0**，在 [Releases](../../releases/latest) 页面下载：

| 系统 | 下载哪个 | 说明 |
|---|---|---|
| Windows | `memo-desk-windows-v1.1.zip` | 解压即用，无需安装 |
| macOS | `memo-desk-mac-v1.1.zip` | M 系列 / Intel 两个 app，首次运行一次脚本 |

**Windows 三步（照抄就行）**

1. 右键 zip → **「全部提取…」**（或双击打开后点最上面的「全部解压缩」），解压到**桌面**这类固定位置
   - ⚠️ **不要在压缩包窗口里直接双击里面的文件** —— 那只是临时预览，程序主体没解出来，会报 `80070002`
   - ⚠️ 别解压到微信/QQ 的接收目录或 Temp，那些地方会被自动清理，笔记会跟着丢
2. 进 `memo-desk` 文件夹，**确认能看到 `node_modules` 这个文件夹**（90 多 MB 的程序主体）。看不到就是没解压完整，回第 1 步
3. 双击 **`启动备忘录.vbs`**（不要双击 `electron.exe`）

> **属性里找不到「解除锁定」？** 那是正常的 —— 只有被 Windows 标记成"来自网络"的文件才有这个勾选框。
> 有就勾上再解压，没有就直接跳过，不用改任何设置。真正要看的是双击后弹不弹安全警告；
> 弹了就双击同文件夹里的 **`一键修复.bat`**，它会自动清标记、关掉残留实例并重新打开。

**macOS 三步**

1. 完整解压整个文件夹（两个 app 和「首次运行.command」要在同一层）
2. 双击 **`首次运行.command`** —— 自动判断芯片、解除系统拦截、补权限并启动
   - 被拦了就右键该文件 →「打开」→ 再点「打开」；或 系统设置 → 隐私与安全性 → 底部「仍要打开」
3. 以后直接双击 `MemoDesk-M.app`（M 系列）或 `MemoDesk-Intel.app`（Intel）

## 怎么打开

**推荐：双击桌面上的「侧边备忘录」快捷方式**（已创建好，图标用的是程序自带图标，不会弹黑窗）。

如果快捷方式丢了，也可以直接双击项目文件夹里的 **`启动备忘录.vbs`**；想重建桌面快捷方式就运行 **`重建桌面快捷方式.py`**。

启动后屏幕右侧会出现备忘录面板；如果它已经缩成边缘一条蓝紫色细条，把鼠标移到细条上就会滑出。

> **双击后完全没反应（没有面板、没有托盘图标）？** 这是 Chromium 沙箱在部分 Windows 电脑上初始化失败，
> `electron.exe` 会**静默退出（退出码 3、没有任何报错）**，看着就像没运行。
> 所有启动脚本（`启动备忘录.vbs` / `.bat`、开机自启、桌面快捷方式）都已带上 `--no-sandbox`，
> 直接双击即可。若手动用命令行运行，也必须带这个参数：
> `node_modules\electron\dist\electron.exe . --no-sandbox`
> 详细排查见「面板找不到-自救说明.md」最后一节。

## 日常使用

| 想做什么 | 怎么做 |
|---|---|
| 展开 / 收起 | 鼠标**靠近**屏幕右缘 → 缓缓滑出；鼠标移开约 1 秒 → 自动收回 |
| 不想让它自动收回 | 点顶栏的 **📌 图钉**（锁定展开），再点一次取消 |
| **换窗口位置** | 点顶栏 **⇱** → 选「右侧贴边 / 顶部贴边 / 小浮窗」（也可在托盘右键菜单里切换）。切换后程序**自动重启一次**，这是为了彻底避开切换后界面卡住，笔记不会丢 |
| **换唤出方式** | 点顶栏 **⇱** → 「唤出方式」：① 鼠标碰到边缘就摊开（默认）② 边缘只留一条 **8px 细把手**，点它才打开。后者鼠标移开照样自动收回 |
| **改页面大小** | 按住**右下角小三角**（或右/下边缘那一小段）拖动即可；同一个菜单里「恢复默认页面大小」复位。尺寸按模式分别记住 |
| 移动窗口 | **按住窗口顶部标题栏拖动**（三种模式都可以拖）。小浮窗收成气泡后，**直接拖气泡也能换位置**，不用先展开 |
| 切换外观样式 | 点顶栏 **🎨** → 选「毛玻璃 / 暗夜玻璃 / 简约浅色」（也可在托盘右键菜单里切换） |
| 曲线排布开关 / 调弧度 | 点顶栏 **∿** 一键开关曲线；或在 🎨 菜单里拖动「曲线弧度」滑块 |
| 新建备忘 | 点右上角 **「+ 新建」**，填好标题、截止日期、优先级、标签、正文，点「保存」 |
| 查看详情 | 点任意卡片 → 进入详情页（可看到完整正文和截止日期），左上角「‹ 返回」 |
| 快速设截止日 | 详情页里有「今天 / 明天 / 3天后 / 一周后」一键按钮 |
| 标记完成 | 点卡片左边的 **方框**，完成后卡片变灰沉底 |
| **删除** | 两个入口：**鼠标悬停卡片 → 右上角出现 🗑**，点它；或进详情页点右上角「🗑 删除」。都会先弹确认框，不会误删 |
| 搜索 | 顶栏搜索框可搜标题、正文、要求清单、标签 |
| 筛选 / 排序 | 标签行点击筛选；右侧下拉可按截止日期 / 优先级 / 创建时间排序 |

## 三种窗口位置

| 模式 | 说明 |
|---|---|
| **右侧贴边**（默认） | 靠在屏幕右缘，收起后整窗推出屏幕（划边模式）或只留一条 8px 细把手（点击模式） |
| **顶部贴边** | 横在屏幕上方，卡片自动变成多列铺开（此模式下曲线排布暂停） |
| **小浮窗** | 320×430 的小窗，可以拖到屏幕任意位置，位置会被记住；不自动收起，点 **›** 会缩成一颗显示待办数的圆角小气泡，点气泡再展开；**收起后的气泡也能直接拖着换位置** |

切换入口：顶栏 **⇱** 按钮，或托盘右键菜单「窗口位置」。
**切换模式会保存设置并自动重启程序**（约 2 秒）——窗口尺寸、页面 CSS 模式类、贴边坐标基准会同时变化，
重启是唯一能保证三者一致、不出现「窗口变了但界面卡住」的做法。

### 两种唤出方式

| 方式 | 表现 |
|---|---|
| 鼠标碰到边缘就摊开（默认） | 鼠标压到屏幕边缘 → 面板滑出；移开 → 自动收回 |
| 边缘细把手，点击才打开 | 收起时屏幕上只有一条 **8×84px** 的小条（右侧竖 / 顶部横），不挡桌面；**划过不会弹出**，点它才展开；展开后鼠标移开仍会自动收回 |

小浮窗模式使用自己的气泡，不受这项设置影响（它本来就不响应鼠标划边）。
设置存在 `memo-data.json` 的 `settings.wakeMode`。

## 要求清单与图片（详情页）

- **要求清单**：详情页下方可以一条条添加要求（比如「例题 5.3 必做」），每条可勾选完成；卡片上会显示进度徽章 `☑ 2/3`，全部完成变绿。
- **图片**：**在任意网页/聊天窗口截图或复制图片后，直接 Ctrl+V 就能贴进来**；也可以点 **「📋 粘贴剪贴板图片」** 按钮，或者把图片文件直接**拖进详情页**。
  - 在**列表页**按 Ctrl+V 更省事：会自动新建一条备忘并把图片放进去
  - 截图工具、微信/QQ 截图、网页右键复制图片都能识别（走系统原生剪贴板）
  - 图片存在本地 `memo-userdata\images\`（程序文件夹内），卡片上显示前 3 张缩略图
  - 详情页里**点图片**会用系统看图软件打开大图；点缩略图右上角 **×** 移除；「清空」一键全移
  - 没被任何备忘引用且超过 24 小时的图片文件会在保存时自动清理

## 开机自启

**已经帮你开启了**（写入了注册表 Run 项，开机后会自动静默启动并展开面板）。

想关闭/再开启：**托盘图标右键 → 开机自启**，打勾即开。它和系统启动项是同一处，不会重复启动。

## 倒计时与提醒

- 卡片上的日期标签自动倒计时：`剩 N 天`，**3 天内变橙色、已逾期变红色**，一眼看出轻重缓急。
- 到了截止时间会弹 **Windows 系统通知**提醒（每个备忘只提醒一次）。

## 生效时段（固定开始 / 结束时间）

有些任务只在一段时间里有效（选课窗口、报名期、课程/值班时段）。详情页「生效时段」里填开始、结束两个时间，两个都是可选的：

- **没到开始时间**：卡片一直显示，但灰掉并标 `未开始`；**到点自动变 `进行中`**，过了结束时间标 `已结束`，状态每 30 秒自动刷新，不用重启。
- **过了结束时间不算完成**：`done` 不变、待办数仍包含它、也不会自动隐藏或自动打勾，仍由你自己决定做没做完。
- 卡片上直接写出区间（如 `11/20 09:00 → 11/25 18:00`）；结束早于开始时会自动对调并提示。
- 两个都留空就是普通备忘，行为与以前完全一致；老数据没有这两个字段也不会受影响。
- 设了「每天 / 每周 / 每月」重复时，**只取填写的时分**套到当前这一期（例：每周三 `10:00 → 11:40`），日期由重复规则决定；跨午夜 `22:00 → 01:00` 会自动把结束顺延一天。
- 数据与 `due`、`doneUntil` 完全独立（`startAt` / `endAt`），不改动重复备忘的完成态逻辑。时段本身**不弹系统通知**，只有原来的截止日期会提醒。

## 重复备忘（每天 / 每周固定某几天 / 每月固定某号）

在详情页的「重复」里选一个节奏：不重复 / 每天 / 每周 / 每月。选了每周会露出「一二三四五六日」多选，选了每月会露出号数下拉。

- **重复备忘没有截止日期**：选中重复后，「截止日期」那一栏会自动隐藏，换成一行说明。到期时间和下一次什么时候出现，全部由规则自己排。
- 列表里始终只有一张卡，代表「当前这一期」，卡面上用 🔁 标出规则（如 `🔁 每周一、四`，连续完成会加 `· 连续N次`），**不再显示「剩 N 天 / 已逾期」**。
- 打勾完成 **不归档**：本期保持已完成（灰掉、排到列表末尾、不再提醒，卡面显示 `· 本期已完成`），直到下一期开始才自动变回未完成、重置要求清单。刷新、关掉重开都不会又冒出来。想撤销就再点一次 ✓。
- 内部用 `due` 记录下一期锚点、`doneUntil` 标记本期完成到什么时候；连续完成会累加 `连续N次`。某一期没做完就被跨过去，下次打开时自动补跳到今天并且连续次数清零。
- 每天/每周的备忘一样会弹系统通知提醒（到点的那一期提醒一次）。

## 托盘设置

屏幕右下角托盘区有蓝色便签图标，右键它可以：

- **展开 / 收起**：鼠标点一下也能切换
- **锁定展开**：和图钉一样的效果
- **窗口位置**：右侧贴边 / 顶部贴边 / 小浮窗，还有「重置小浮窗位置」
- **始终置顶**：默认开启（面板永远浮在别的窗口上面）；如果觉得挡事可以关掉
- **开机自启**：打开后每次开机自动运行
- **打开数据文件所在目录**：直接定位备份文件
- **退出**：彻底关闭程序

## 数据保存在哪

所有备忘保存在**程序文件夹里的 `memo-userdata\memo-data.json`**：

```
<你放程序的文件夹>\memo-desk\memo-userdata\memo-data.json
```

（托盘右键 → 「打开数据文件所在目录」可以一步跳到。）

> **2026-11-02 起数据目录改到这里了。** 原来放在 `%APPDATA%\memo-desk\`，
> 但部分 Windows 机器上那个目录会被系统拒绝写入（报错 0x5），后果是：
> 单实例锁建不出来导致多开、笔记互相覆盖（删除不保存）、托盘图标写不出来、
> 日志全空。搬到程序目录后这些全部消失。
> 首次启动会自动把旧数据**复制**过来（旧文件保留，不删除），所以不会丢笔记。

想备份就把 `memo-userdata` 整个文件夹复制一份；想换电脑就把整个程序文件夹
（含 `memo-userdata`）一起拷过去，双击即用。

## 常见问题

**Q：屏幕右侧找不到它了？**
点一下托盘里的蓝色便签图标就能唤出。

**Q：它挡住了别的窗口？**
点图钉收起，或在托盘菜单关掉「始终置顶」。

**Q：想修改界面（颜色、宽度等）？**
界面文件在 `src/` 文件夹：颜色在 `styles.css` 开头的 `:root` 区域，逻辑在 `app.js`，改完重新双击 `启动备忘录.vbs` 即可生效。

**Q：启动时闪了个黑框？**
那是 `启动备忘录.bat`（备用方式），平时用 `.vbs` 启动就没有黑框。
