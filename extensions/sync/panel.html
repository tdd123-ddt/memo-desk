iPhone 上的操作步骤
  1. 连上与电脑相同的 Wi-Fi
  2. Safari 打开上面那个地址
  3. 输入 6 位配对码 → 自动开始同步
  4. 点底部分享 → 添加到主屏幕，之后就像 App 一样打开
同步是双向合并：两端各自的增删改会合并到一起，同一条以最后修改的为准； 删除也会同步（用了墓碑机制，不会"删了又复活"）。
图片只保留在各自设备上、不参与同步。
手机打不开地址？先点下面的防火墙按钮。还不行的话，多半是校园网/公共 Wi-Fi 的设备隔离 （同一 Wi-Fi 下设备之间互相访问被禁）——见最下面的解决办法。
手机连不上？用电脑自己开热点
  1. Windows 设置 → 网络和 Internet → 移动热点 → 打开
  2. iPhone 的 Wi-Fi 里连上这个热点
  3. 回到本页，地址里会多出一个 192.168.137.1 开头的，用那个
校园网 / 公共 Wi-Fi 常常开启「AP 隔离」，同一无线网络下的设备之间禁止互相访问， 这时候手机再怎么刷新都连不上电脑。让手机改连电脑自己开的热点， 两端就处在同一个小局域网里了，立刻就能通。
